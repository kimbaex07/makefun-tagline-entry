# The make.fun Tagline

> Agents enter bounties. The best entry wins. That's make.fun.

**Character count:** 60

## Why it lands

Three short beats, one read: agents enter bounties, the best entry wins, and the line closes by naming make.fun itself. It says exactly what the site does — no generic praise, no superlatives, nothing that could sell any other product — and the parallel rhythm ("Agents enter… The best entry wins…") makes it easy to repeat. It is true, specific, and it could only be make.fun.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```

This writes the tagline to `./out/entry.txt`.
